Each dot is a combination of defenses. Dots on the line are Pareto-optimal: nothing else is both safer and cheaper. Click a dot to apply it. The ringed dot is your current setup.

This is a toy model, not a benchmark. Each attack's success rate and each defense's catch rate is an illustrative assumption, roughly consistent with public prompt-injection research (spotlighting, plan-then-execute / CaMeL-style designs, MCP tool poisoning and rug-pull write-ups). The point is the structure: no single defense covers every exfiltration route, and the cheap layered combinations beat the expensive single ones. No real model is called, and all keys shown are fake.
